# the-last-firefly
A small 2D forest adventure made with Python and Pygame.

The Last Firefly

A small 2D forest adventure made with Python and Pygame.

How to Play

Use the arrow keys to move.

Collect 5 fireflies to save the forest.

Press R after winning to play again.
